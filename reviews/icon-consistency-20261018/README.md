# Loon Routing DNS · 图标视觉一致性审核稿（2026-10-18）

> **仅用于设计审核，尚未替换 main 正式版的任何 PNG、策略组或插件图标。** 与 GitHub 中的正式 `icons/v20261018/` 文件无关。图册及尺寸预览另见对话附件；此分支提供可编辑 SVG 源文件与审核结论。

## 需要改正的视觉差异

已检查正式版的实际 PNG 而非仅依靠预览。部分 Apple App Store 当前素材自带明显的玻璃边缘／浮雕造型，与纯色扁平图标混用时形成风格差异；统一圆角蒙版也不能去掉素材已包含的高光。

| 程度 | App Store 官方候选 | 观察与后续选择 |
|---|---|---|
| 显著玻璃／高光边缘 | Netflix、Spotify、Telegram、Discord、HBO、Instagram | 在原图可见外框或发光/浮雕主体；优先核对官方品牌资产是否存在更克制的变体，再做同尺寸预览 |
| 局部边缘高光 | TikTok | 具轻微立体框边；优先与平面候选对照，避免不必要的改造 |
| 以纯色／清楚符号为主 | YouTube、Twitch、Facebook、WhatsApp、LINE、LinkedIn、X | 暂不处理，也不统一补加玻璃或投影 |
| 原品牌视觉或活动标记 | ABEMA 等 | 不要把官方图标中的动态推广元素错误认为我们额外加的 UI；应单独确认版本与品牌一致性 |

修改官方视觉素材之前，要核对品牌使用条款；不要把官方 App Store 图片重绘、去标、去高光并默认视作获得权利人的允许。

## 三枚原创重做方案

- **Proxy**: 从旧的拱形门洞更换为有方向性的 P 字标。主轮廓采用简单实心几何，避免锁孔或泛用网络流程图。
- **AI**: 废弃三段旋涡／加载标记，改为定制几何 AI 字标，与 Auto 及品牌 AI App 的视觉区分更明确。
- **Console**: 废弃拼接 L 和无意义装饰圆点，采用 Loon Routing 首字母 LR 的独立字标。仍需与项目命名及 README 视觉联合审查。

共同规范：一个明确视觉中心；没有玻璃边框、霓虹、统一渐变模板；独立颜色系统；512px SVG 画板，可导出 32/48/64/128/512/1024px PNG；必须在明暗两种列表背景检查缩小后的结构。

## 审核与合并条件

1. 核对新旧并排对照，确认三枚图标不仅颜色而是主体真正变化。
2. 检查在 32px 和 48px 的辨识度、边缘和留白；若用作 Loon 正式应用图标，还应在真机观察。
3. 对七枚高光明显的官方图标，收集官方可用的平面商标版本，并按品牌个别决定是否替换；不得自动批量去玻璃。
4. 用户确认后在新版本目录发布 PNG，更新 33 个策略组和 Console 图标 URL，并同步图标清单、构建脚本与版本化插件引用以避免缓存问题。

不涉及节点、DNS、规则、插件功能行为。
