# Loon Routing DNS 策略组图标
本目录包括 v4.4.7 正式配置所引用的全部 33 枚透明 512×512 PNG，统一扁平化，无 App 背景板。已在 icon-pretest 分支通过实机图标显示测试，正式配置不需要再调用上游图标仓库。

`動畫瘋` 采用文件名 `AnimeCrazy.png` 以避免 URL 中文路径问题；其余 32 个文件名与策略组名称一致。

图标为测试分支按统一视觉规范重新制作的符号，其中部分品牌符号由 Simple Icons（CC0）提供基础路径，品牌商标仍属于各自权利人。详见 [来源清单](./ICON_SOURCE_REPORT.json) 及 [生成器](../scripts/generate-policy-icons.mjs)。图标审核针对本项目列表使用，并非品牌官方认证。
