# Loon Routing DNS pretest icons

33 self-hosted flat transparent 512x512 PNG files. These are **test vector reconstructions** inspired by the approved palette and symbols; they are not byte-identical to the original generated review PNG assets. Some brand vector paths use Simple Icons (CC0), subject to their respective trademarks. No external icon hosting is needed at runtime.
