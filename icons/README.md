# LoonKit 图标

正式配置使用 **33 个策略组图标**，网络辅助插件另使用 `Console.png`。共 34 个 PNG 图标，现统一保存在 [正式图标目录](./v20261021r1/)；HBO 与其他服务使用同一目录、同一固定版本，不再单独说明或维护。

[SVG 原稿](./source/) 仅供人工编辑。更新图标时应新增经过验证的版本快照、更新固定提交引用，并在 Loon 明暗模式下核对效果；不要覆盖已经发布的历史快照。

旧 PNG 版本目录从 `main` 清理，但已发布配置所使用的**固定 Git 提交历史不改写**，原有订阅链接仍可解析到其对应的历史文件。
