# LoonKit 正式图标

正式 v6.0.0 配置使用 33 个策略组图标，网络辅助插件另外使用 `Console.png`。已发布资源均采用固定 Git 提交和版本化目录。

- [32 个策略组图标](./v20261018r2/)：除 HBO 外。
- [HBO 图标](./v20261018r3/HBO.png)。
- [网络辅助插件图标](./v20261018r2/Console.png)。
- [保留的 SVG 原稿](./source/)：用于人工调整原稿；不得直接覆盖已发布 PNG。

更新时在独立分支新增图标版本目录，核查 PNG、Loon 明暗界面和用户配置引用后，再发布新版本；不要覆盖现有固定 Raw URL。当前仓库没有自动抓取或生成正式图标的工具，避免网络获取的数据未经人工审核就替换现役素材。

图标中涉及的第三方品牌名称与标志保留其原有商标及版权；顶层 GPL-2.0-only 只适用于 LoonKit 有权授权的原创部分，不自动为品牌图片重新授权。需要重新发布或替换图标时应确认素材来源和允许的用途。参见[第三方许可与来源声明](../docs/THIRD_PARTY_NOTICES.md)。
