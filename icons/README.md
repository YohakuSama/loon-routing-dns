# LoonKit 原创中性图标

正式配置使用 **33 个策略图标**，网络辅助插件另使用 1 个 `Console.png`。现役共 34 个 PNG，位于 [`icons/v20261021r2/`](./v20261021r2/)，固定资源提交为 `d9333b47b1a0361d911fc57e3dc5808683d416d5`。

这些图标由 [`scripts/build_neutral_icons.py`](../scripts/build_neutral_icons.py) 使用 Python 标准库确定性生成：圆角配色、简化装饰和人工定义的英文字母缩写，不复制第三方 App 图标、商标轮廓或品牌专用字体。品牌名称只作为用户辨认策略用途的描述，不表示官方授权或合作。

旧品牌标志图片及 SVG 原稿从现役分支移除；**历史固定提交仍可能保留旧资产**，不能把当前的原创图标声明扩展为对过去第三方素材的权利证明。维护旧固定引用的用户可通过更新正式配置切换新图标。

更新需创建新快照目录、先提交静态资产，再固定引用 SHA 并核对明暗模式下的可读性；不得覆盖已发布的固定资源。第三方规则许可见[声明](../docs/THIRD_PARTY_NOTICES.md)。
