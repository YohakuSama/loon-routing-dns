## 实机测试

复制下面的完整配置地址导入 Loon：

```text
https://raw.githubusercontent.com/YohakuSama/loon-routing-dns/icon-pretest/Loon_Routing_DNS.lcf
```

先备份现有配置和个人节点订阅。新配置不会自动包含你的私有订阅。依次检查 33 组是否显示图片、浅色/深色主题是否可识别、是否存在遮挡或重复；同时测试代理节点与 DNS 分流。
