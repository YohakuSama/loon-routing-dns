# LoonKit v6.3.0 配置校验

正式配置 `LoonKit.lcf` 的 SHA256：

```text
75864720496132550b4cded4b27c78cd00ea8bdc49500daa9a7c5adc31653d9e  LoonKit.lcf
```

从 [v6.3.0 Release](https://github.com/YohakuSama/loonkit/releases/tag/v6.3.0) 下载 `LoonKit.lcf` 和 `SHA256SUMS` 到同一目录，运行：

```bash
sha256sum -c SHA256SUMS
```

已发布的历史版本单独保留，不会被新版覆盖。
