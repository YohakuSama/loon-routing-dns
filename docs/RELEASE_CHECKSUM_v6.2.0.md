# LoonKit v6.2.0 配置校验

LoonKit.lcf 的 SHA256：

```text
60af6e40a1fd3794f803724eecd5ed02051af4c58a170113b46f53b6c9dbb534  LoonKit.lcf
```

从 [v6.2.0 Release](https://github.com/YohakuSama/loonkit/releases/tag/v6.2.0) 下载配置与 `SHA256SUMS` 到同一文件夹后，执行：

```bash
sha256sum -c SHA256SUMS
```

发布附件固定版本，不会覆盖已有的 v6.0.0 或 v6.1.0 版本。
