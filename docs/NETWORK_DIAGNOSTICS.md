# 网络辅助

一个插件提供节点信息、网络检测和解锁检测三个工具。

[查看插件](../release/Network_Diagnostics.plugin) · [返回首页](../README.md)

## 节点信息

查看所选节点或策略的公网出口、地区与运营商信息。插件设置中的「检测策略」默认是 `Proxy`，也可以从节点菜单直接选择某个节点。

## 网络检测

检查直连、代理及 DNS 状态。原生 DNS 查询需要 Loon Build 988 或更高版本。

## 解锁检测

从节点菜单运行「解锁检测」，所有请求均使用该节点；从插件菜单运行则使用设置中的「检测策略」。无需选择单个服务。

默认快速检测涵盖 Netflix、Disney+、YouTube Premium、Spotify、TikTok、ChatGPT、Gemini 和 Claude。需要更多内容时，在插件设置中打开「完整检测」，再检查 Prime Video、Apple 地区、Bilibili 大陆及港澳台、BBC iPlayer 和 Abema。

检测参考服务专用接口、标题页、CDN 出口及页面字段。CDN 地区仅是出口信息，不证明播放权限。结果区分「可能可用」「部分可用（初步）」「地区受限」「识别地区」「仅可访问」「请求超时」「连接异常」和「未确认」。仅识别到出口国家或网页响应时，不会宣称流媒体已解锁。平台更改接口时，可能需要更新检测器。结果末尾会显示当前检测脚本版本，供排查插件缓存。

检测使用限流并发，网络出现短暂请求错误时最多重试一次。默认最长等待约 16.5 秒，完整检测最长约 23 秒；通常无需等到上限。**这是脚本的等待上限，不等于所有项目都能完成检测。** 多项连接异常时会提示检查节点；单项未完成时如实显示超时。不会在后台自动检测，也不会读取账号信息。

即使显示地区可用，也不保证账号登录、订阅权益和视频播放实际成功。

## 网络切换提醒

默认关闭，网络变化后连续检测失败才通知；不会改动节点或 DNS。

从旧版本更新时，请在 Loon 中刷新配置、远程插件和脚本。若弹窗末尾没有「检测器 v6.3.4」，说明仍在运行旧脚本；请检查所导入的配置与远程插件是否已刷新。历史单独安装的服务诊断插件可删除，以免出现重复入口。
