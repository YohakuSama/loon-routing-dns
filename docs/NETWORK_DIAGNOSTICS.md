# 网络辅助

LoonKit 默认内置一个「网络辅助」插件，包含节点信息、网络检测和服务检测三个手动工具，并提供可选的网络切换提醒。

[查看插件](../release/Network_Diagnostics.plugin) · [返回首页](../README.md)

## 节点信息

查看所选节点或策略的公网 IP、地区、运营商及网络归属。默认查询 `Proxy`；从节点菜单启动时可针对该节点查询。需要时可以开启「直连 IP 对照」，比较两条连接的公网出口。

## 网络检测

分别检查直连网络、`Proxy` 策略的连接情况，以及 Loon 的 DNS 解析状态。

- **正常**：检测地址返回预期结果，DNS 查询有有效地址。
- **暂未确认**：检测地址返回其他响应，或当前 Loon 版本不支持某项检查；不等同于网络故障。
- **连接或解析失败**：请求超时、连接失败或 DNS 查询明确报错，可按提示检查网络和日志。

DNS 检测支持自选解析器，不限制必须使用 AliDNS。缓存结果只说明曾经解析成功；一次 DNS 检测不能证明所有 App 都使用同样的 DNS，也不能保证没有 DNS 泄漏。原生 DNS 查询需要 **Loon Build 988 或更新版本**。

## 服务检测

在插件设置中找到「检测服务」，先选择目标，再手动运行「服务检测」。**初始值为「请选择服务」，不会自动检测 Spotify 或其他服务。**

可选服务：Spotify（音乐）、Twitch（直播）、Abema（视频）、BBC（资讯）、LINE（通讯）、Reddit（社区）、LinkedIn（职场）。

结果按「网站」「相关资源」「DNS 解析」三个项目展示。检测地址收到 HTTP 404 等响应时显示「有响应」，不会直接断言应用异常；只有发生连接、TLS 或 DNS 错误时才提示检查方向。

此工具检测的是网站连接与 DNS，不能代替实际登录、播放、消息收发、地区权限及 UDP/IPv6 网络质量检查。既不会自动切换节点，也不会读取账号资料或上传私人日志。

如果从早期版本升级，曾经**另行安装**独立服务诊断插件，请在 Loon 中删除旧的独立安装项，以免出现两个插件入口。导入新配置后需刷新插件及脚本资源。

## 网络切换提醒

**默认关闭。** 开启后，在网络切换时进行两次直连检查，连续失败才发送一次提醒；相同提醒有 30 分钟间隔。此功能不会自动更改节点、DNS 或代理设置。
