# 网络辅助

一个插件提供节点信息、网络检测和解锁检测三个工具。

[查看插件](../release/Network_Diagnostics.plugin) · [返回首页](../README.md)

## 节点信息

查看所选节点或策略的服务器配置地址和公网出口，以及出口地区与运营商信息。入口来自 Loon 节点配置（若可获得），不代表中转链路的真实第一跳。插件设置中的「检测策略」默认是 `Proxy`，也可以从节点菜单直接选择某个节点。开启「直连 IP 对照」后，直连与代理出口会同时查询；该选项默认关闭。

## 网络检测

检查直连、代理及 DNS 状态。原生 DNS 查询需要 Loon Build 988 或更高版本。

## 解锁检测

在 Loon 节点菜单中运行「解锁检测」，所有请求都走选中的节点。插件菜单运行时则使用「检测策略」指定的节点。

**仅检测七项服务：** DAZN、Discovery+、Paramount+、Disney+、Netflix、ChatGPT、YouTube Premium。不再检测 Gemini、Spotify、TikTok、Claude，也不提供「完整检测」选项。

结果直接显示「**已解锁**」「**未解锁**」「**检测失败**」。Netflix 返回 404 时按参考脚本显示「**仅自制剧**」。检测到地区时在结果后标示，例如「已解锁（JP）」。

检测主要采用上述平台的公开页面、地区接口或测试影片响应。200、302、403、404 等状态的解释按各平台分别处理，**网页或地区检测不能验证实际账号会员和视频播放权益**；无法获得有效响应时显示检测失败，而不是猜测节点未解锁。

安全验证拦截不能自动等同于地区限制；遇到没有明确地区结论的接口异常，显示「检测失败」。

整个检测设有请求并发和超时保护，不改变节点选择、DNS 或分流规则。

## 网络切换提醒

默认关闭，网络变化后连续检测失败才通知；不会改动节点或 DNS。

从旧版本更新时，请在 Loon 中刷新配置、远程插件和脚本。若弹窗末尾没有「检测器 v6.4.4」，说明仍在运行旧脚本；请检查所导入的配置与远程插件是否已刷新。历史单独安装的服务诊断插件可删除，以免出现重复入口。
