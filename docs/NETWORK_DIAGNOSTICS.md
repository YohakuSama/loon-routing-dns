# 网络辅助

一个插件提供节点信息、网络检测和解锁检测三个工具。

[查看插件](../release/Network_Diagnostics.plugin) · [返回首页](../README.md)

## 节点信息

查看所选节点或策略的服务器配置地址和公网出口，以及出口地区与运营商信息。入口来自 Loon 节点配置（若可获得），不代表中转链路的真实第一跳。插件设置中的「检测策略」默认是 `Proxy`，也可以从节点菜单直接选择某个节点。开启「直连 IP 对照」后，直连与代理出口会同时查询；该选项默认关闭。

## 网络检测

检查直连、代理及 DNS 状态。原生 DNS 查询需要 Loon Build 988 或更高版本。

## 解锁检测

从节点菜单运行时使用所选节点；从插件菜单运行时使用插件设置中的「检测策略」。一键检查常用流媒体与 AI 服务，无需逐项选择。

默认检查 Netflix、Disney+、YouTube Premium、Spotify、TikTok、ChatGPT、Gemini 和 Claude。开启「完整检测」可增加 Prime Video、Apple 地区、Bilibili 大陆及港澳台、BBC iPlayer 和 Abema。

结果只保留一行服务状态：

- **支持**：平台返回明确地区支持信息、有效内容信号，或该服务可识别的正常页面响应；不保证账号登录、会员权益或实际影片播放。
- **部分支持**：Netflix 的一般测试影片无法确认，但自制内容测试获得有效响应。
- **不支持**：有明确的地区限制或拒绝服务信号。
- **待确认**：当前能取得部分信息，但不足以判定支持与否；不会把普通网站连接当作片库解锁。
- **检测失败**：请求未成功或超过检测时间。Apple 地区会直接显示地区码。

地区已确认时显示在状态后，例如「支持（JP）」。网络检测不改变分流、DNS 或节点。安全验证拦截不等于地区限制，Gemini 等服务的页面访问也不等于拥有登录权限。

优先使用少量、直接的服务接口，不因某个接口失效就直接把节点判成不支持。快速检测最多约 18 秒，完整检测最多约 26 秒；实际使用仍以对应 App 为准。

## 网络切换提醒

默认关闭，网络变化后连续检测失败才通知；不会改动节点或 DNS。

从旧版本更新时，请在 Loon 中刷新配置、远程插件和脚本。若弹窗末尾没有「检测器 v6.4.3」，说明仍在运行旧脚本；请检查所导入的配置与远程插件是否已刷新。历史单独安装的服务诊断插件可删除，以免出现重复入口。
