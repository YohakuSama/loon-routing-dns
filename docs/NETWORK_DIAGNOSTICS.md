# 网络辅助

一个插件提供节点信息、网络检测和解锁检测三个工具。

[查看插件](../release/Network_Diagnostics.plugin) · [返回首页](../README.md)

## 节点信息

查看所选节点或策略的服务器配置地址和公网出口，以及出口地区与运营商信息。入口来自 Loon 节点配置（若可获得），不代表中转链路的真实第一跳。插件设置中的「检测策略」默认是 `Proxy`，也可以从节点菜单直接选择某个节点。开启「直连 IP 对照」后，直连与代理出口会同时查询；该选项默认关闭。

## 网络检测

检查直连、代理及 DNS 状态。原生 DNS 查询需要 Loon Build 988 或更高版本。

## 解锁检测

从节点菜单运行「解锁检测」，所有请求使用选中的节点；从插件菜单运行则使用「检测策略」。

仅检测 DAZN、Discovery+、Paramount+、Disney+、Netflix、ChatGPT、YouTube Premium 七项。检测接口、地区读取、状态判断及结果文字按原参考脚本执行。

DAZN 从启动接口读取地区；Discovery+ 通过令牌查询所属地区；Paramount+ 依据 HTTP 200/302 判断；Disney+ 依据 BAMTech 地区会话判断；Netflix 依据 HTTP 200/403/404 判断；ChatGPT 根据首页响应和地区列表判断；YouTube Premium 根据页面地区限制提示和地区信息判断。

弹窗直接显示参考脚本对应结果，不增加其他提示。网络设置和分流不受检测影响。

## 网络切换提醒

默认关闭，网络变化后连续检测失败才通知；不会改动节点或 DNS。

从旧版本更新时，请在 Loon 中刷新配置、远程插件和脚本。若弹窗末尾没有「检测器 v6.4.5」，说明仍在运行旧脚本；请检查所导入的配置与远程插件是否已刷新。历史单独安装的服务诊断插件可删除，以免出现重复入口。
