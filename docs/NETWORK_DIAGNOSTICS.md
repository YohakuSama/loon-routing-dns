# 网络辅助

一个插件提供节点信息、网络检测和解锁检测三个工具。

[查看插件](../release/Network_Diagnostics.plugin) · [返回首页](../README.md)

## 节点信息

查看所选节点或策略的服务器配置地址和公网出口，以及出口地区与运营商信息。入口来自 Loon 节点配置（若可获得），不代表中转链路的真实第一跳。插件设置中的「检测策略」默认是 `Proxy`，也可以从节点菜单直接选择某个节点。开启「直连 IP 对照」后，直连与代理出口会同时查询；该选项默认关闭。

## 网络检测

手动检测当前节点、直连网络与 DNS 状态。优先使用节点菜单中选定的节点；从插件入口运行时，使用「检测策略」解析出的最终节点。若无法确定具体节点，不会把 Proxy 策略组延迟冒充为单节点延迟。

节点与直连测试都访问 `http://bing.com/generate_204`，与 LoonKit 配置的测速目标一致。显示的是脚本 HTTP 请求响应耗时，不是 Loon 内置节点延迟，两者数值可能不同。成功条件是 HTTP 204；200、跳转或目标站点异常不直接代表代理断网。

结果使用简洁卡片显示节点连接、直连和 DNS，保留文字结果用于兼容。原生 DNS 查询需要 Loon Build 988 或更高版本。网络切换监测仍只检查直连网络，默认关闭。

## 解锁检测

从节点菜单运行时检测当前选定节点；从插件菜单运行时使用「检测策略」。

检测 DAZN、Discovery+、Paramount+、Disney+、Netflix、ChatGPT、YouTube Premium 共七项。检测逻辑由 LoonKit 自有脚本执行，借鉴公开服务检测的请求与判定方法，不加载第三方脚本。

弹窗只显示「已解锁」「未解锁」「检测失败」，Netflix 可显示「完整解锁」或「仅自制剧」。所有平台统一不展示国家代码；检测仍保留地区判断，不修改实际结果。

安全验证拦截不直接等同于地区封锁。Gemini 不在这七项检测中。Discovery+ 地区码不区分大小写；DAZN 的请求失败原因只写入脚本日志，不进入弹窗。检测不改变节点、DNS 或分流规则。

## 网络切换提醒

默认关闭，网络变化后连续检测失败才通知；不会改动节点或 DNS。

从旧版本更新时，请在 Loon 中刷新配置、远程插件和脚本。若弹窗末尾没有「LoonKit v6.5.0」，说明仍在运行旧脚本；请检查所导入的配置与远程插件是否已刷新。历史单独安装的服务诊断插件可删除，以免出现重复入口。
