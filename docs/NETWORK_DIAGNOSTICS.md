# 网络辅助

LoonKit 内置「网络辅助」，用于查看节点出口、网络连接和服务可用性。

[查看插件](../release/Network_Diagnostics.plugin) · [返回首页](../README.md)

## 节点信息

显示选中节点或策略的公网 IP、地区及运营商。从节点菜单运行时使用该节点；从插件菜单运行时默认使用 `Proxy`，也可在设置中指定检测策略。可选的「直连 IP 对照」用于比较代理与本机出口。

## 网络检测

检查直连、`Proxy` 策略连接和 DNS 解析情况。连接失败、DNS 解析失败和暂时无法判断会分别说明，不把普通网页响应当作网络故障。原生 DNS 查询需要 Loon Build 988 或以上。

## 服务检测

选中节点后运行「服务检测」，无需先挑选 Spotify 或其他品牌。插件会通过**同一节点**检查多个常用服务，并按实际响应展示结果：

- **地区可能可用**：目标页面返回可识别的服务内容，仅为初步判断。
- **网页可访问**：网站能够响应，但无法证明该服务已解锁。
- **地区受限**：检测到明确的地区限制响应。
- **连接失败**：请求无法完成。
- **暂无法判断**：网站返回模糊响应、限流或超时。

从插件菜单运行时使用设置中的「检测策略」，默认 `Proxy`。检测采用有限并发与总超时，只在手动运行时向相关服务网站发送请求，不获取登录信息，也不会切换节点或修改分流规则。

**注意：** 网页可访问不等于可以登录、观看视频或获得会员权益。地区权限和账号状态可能需要在服务 App 内实际验证。网站可能随时修改识别方式，未能判断时不会给出“已解锁”的结论。

## 网络切换提醒

默认关闭。开启后只在网络切换时进行直连检查，连续失败才提醒；不会自动更改节点、DNS 或代理设置。

如果之前手动安装过旧的独立服务诊断插件，可删除旧插件以避免重复入口。导入配置后刷新插件及脚本。
