# 网络辅助

一个插件提供节点信息、网络检测和解锁检测三个工具。

[查看插件](../release/Network_Diagnostics.plugin) · [返回首页](../README.md)

## 节点信息

查看所选节点或策略的服务器配置地址和公网出口，以及出口地区与运营商信息。入口来自 Loon 节点配置（若可获得），不代表中转链路的真实第一跳。插件设置中的「检测策略」默认是 `Proxy`，也可以从节点菜单直接选择某个节点。开启「直连 IP 对照」后，直连与代理出口会同时查询；该选项默认关闭。

## 网络检测

检查直连、代理及 DNS 状态。原生 DNS 查询需要 Loon Build 988 或更高版本。

## 解锁检测

从节点菜单运行时使用选定节点；从插件菜单运行时使用「检测策略」。

检测七项：DAZN、Discovery+、Paramount+、Disney+、Netflix、ChatGPT、YouTube Premium。结果仅显示服务状态、能取得的地区、节点和脚本版本。

按照各平台返回的地区字段和服务响应判断。正常重定向不等于地区封锁；Cookie 和跳转按 Loon 默认行为处理。Netflix 的登录页面不等于影片完整解锁；YouTube 没有识别出地区时不臆测为美国；ChatGPT 不再仅凭旧域名的地区列表认定可用。

请求无法确认结果时显示「检测失败」，不虚报已解锁或未支持。检测不修改 DNS、TUN、分流或节点。

## 网络切换提醒

默认关闭，网络变化后连续检测失败才通知；不会改动节点或 DNS。

从旧版本更新时，请在 Loon 中刷新配置、远程插件和脚本。若弹窗末尾没有「检测器 v6.4.6」，说明仍在运行旧脚本；请检查所导入的配置与远程插件是否已刷新。历史单独安装的服务诊断插件可删除，以免出现重复入口。
