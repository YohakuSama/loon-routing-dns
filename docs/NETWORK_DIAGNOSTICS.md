# 网络辅助插件

LoonKit v6.0.0 的正式配置已包含网络辅助插件，通常不需要重复订阅。[查看正式插件](../release/phase-07/assets/Network_Diagnostics.plugin)。

## 节点出口信息

查看所选节点或策略的公网 IP、地区、ASN、ISP 等信息，默认使用 `Proxy`。可选的「直连 IP 对照」默认关闭，开启后会另外请求直连公网 IP。

## 网络与 DNS 诊断

插件分别检查直连网络、`Proxy` 的 HTTP 连通性和 Loon 原生 DNS 解析。

- **HTTP 204**：对应的连通性检测正常；目标网站重定向等不确定结果不会被直接当成代理故障。
- **DNS 解析成功**：已获得有效 DNS 答案。
- **DNS 协议信息待确认**：例如 Loon 返回 `auto / https://`，只有不完整的查询元数据，不能据此确定实际传输协议。此时直连、代理正常会显示「网络连接正常，DNS 协议信息待确认」。
- **明确异常**：查询失败或 Loon 明确报告本次普通 DNS 查询等情况才显示异常。

插件不会把缓存结果当作本次加密传输的证明。想了解实际传输路径，需要结合 Loon DNS 日志判断。

## 网络切换提醒

该功能**默认关闭**。开启后，网络变化时检查直连连通性；若第一次明确失败会再次检测，两次失败才使用**中文标题与正文**发送通知。同类提醒有 30 分钟冷却，不自动切换节点或改变 DNS、分流设置。

插件仅检测指定网络指标，无法替代设备流量分析或验证所有 App 的 DNS 行为。
