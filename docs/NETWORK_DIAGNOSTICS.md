# 网络辅助

一个插件提供节点信息、网络检测和解锁检测三个工具。

[查看插件](../release/Network_Diagnostics.plugin) · [返回首页](../README.md)

## 节点信息

查看所选节点或策略的服务器配置地址和公网出口，以及出口地区与运营商信息。入口来自 Loon 节点配置（若可获得），不代表中转链路的真实第一跳。插件设置中的「检测策略」默认是 `Proxy`，也可以从节点菜单直接选择某个节点。开启「直连 IP 对照」后，直连与代理出口会同时查询；该选项默认关闭。

## 网络检测

检查直连、代理及 DNS 状态。原生 DNS 查询需要 Loon Build 988 或更高版本。

## 解锁检测

从节点菜单运行「解锁检测」，所有请求均使用该节点；从插件菜单运行则使用设置中的「检测策略」。无需选择单个服务。

默认快速检测涵盖 Netflix、Disney+、YouTube Premium、Spotify、TikTok、ChatGPT、Gemini 和 Claude。需要更多内容时，在插件设置中打开「完整检测」，再检查 Prime Video、Apple 地区、Bilibili 大陆及港澳台、BBC iPlayer 和 Abema。

检测结果采用易于理解的状态：

- **片库可访问**：Netflix 测试影片页面返回有效内容，仍不能代替实际播放。
- **地区支持**：Disney+ 等平台在有效会话中明确返回地区支持状态；不代表账号、订阅或付费内容权益。
- **页面地区**：Gemini 页面返回的国家代码仅用于定位地区，不据此推断服务已解锁或被封锁。
- **Premium 入口支持**：YouTube 页面提供可识别的 Premium 订阅入口，不保证实际付款或会员功能。
- **地区受限**：服务在当前检测响应中明确返回地区限制；普通 403、验证码或安全防护页不作此判定。
- **接口／网站可访问**：ChatGPT Web、iOS API 或 TikTok、Claude 等端点有有效响应；仅代表连接正常，不等于登录、播放或完整解锁。安全验证拦截也不能直接判定为地区限制。
- **未取得有效响应**：服务没有返回足够的判定信息，或检测接口本身发生变化；结果不会强行判成成功或失败。
- **检测超时／连接异常**：请求没有正常完成，不据此判定服务被封锁。

检测只通过当前选中节点发送请求，最多并行六个网络请求。快速检测最长约 19 秒，完整检测最长约 26 秒。短暂请求错误在剩余时间充足时最多重试一次。若目标平台调整检测页面或接口，没有可靠证据便显示「无法确认」，不会假设已经解锁。

实际是否能看视频、登录或享有会员功能，仍应在对应应用中确认。

## 网络切换提醒

默认关闭，网络变化后连续检测失败才通知；不会改动节点或 DNS。

从旧版本更新时，请在 Loon 中刷新配置、远程插件和脚本。若弹窗末尾没有「检测器 v6.3.9」，说明仍在运行旧脚本；请检查所导入的配置与远程插件是否已刷新。历史单独安装的服务诊断插件可删除，以免出现重复入口。
