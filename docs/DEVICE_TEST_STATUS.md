## 回归测试清单

- [ ] **配置加载**：导入 `LoonKit.lcf`，刷新 26 份远程规则、网络辅助插件及图标，检查资源下载状态。
- [ ] **节点信息**：选择具体节点，核对出口 IP、地区、ASN；按需检查入口地址及直连出口对照。
- [ ] **网络检测**：分别检查代理、直连 HTTPS 204 响应和 Loon 原生 DNS 结果；观察异常响应时的状态提示。
- [ ] **解锁检测**：查看 DAZN、Discovery+、Paramount+、Disney+、Netflix、ChatGPT 和 YouTube Premium 的检测结果；必要时结合账号实际播放情况验证。
- [ ] **异常场景**：模拟不可用节点、超时、重定向、验证码及网络切换，检查结果解释和提醒行为。
- [ ] **界面适配**：检查 iPhone 和适用的 iPad 设备上三个诊断入口的换行、长节点名与信息展示。
- [ ] **分流与 DNS/TUN**：复测国内直连、AI/媒体策略、广告拦截、IPv4/IPv6 与 DNS/TUN 的实际行为。
- [ ] **隐私与安全**：确认诊断输出未包含凭据；共享问题记录时先移除个人 IP、节点、Cookie 和 Token。

逐项记录建议包含测试日期、设备与 Loon 版本、预期结果、实际结果及必要的脱敏证据。清单仅在相应测试完成并记录后勾选。
