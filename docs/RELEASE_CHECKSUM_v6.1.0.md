# LoonKit v6.1.0 配置校验

新版配置文件的 SHA256：

```text
19de1c36ee747ea76512af3bf5b2d62475e77175db09a2568ce8de43a82e480b  LoonKit.lcf
```

下载 [v6.1.0 Release 配置](https://github.com/YohakuSama/loonkit/releases/download/v6.1.0/LoonKit.lcf) 和同一 Release 的 `SHA256SUMS` 到同一文件夹后运行：

```bash
sha256sum -c SHA256SUMS
```

该哈希对应新正式版的配置文本，不适用于历史 v6.0.0 配置。正式规则仍固定引用已发布的远程资源。
