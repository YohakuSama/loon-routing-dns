# LoonKit v6.0.0 — 更新记录

当前正式版本包含 26 份固定远程规则（197,765 条匹配）、106 条本地规则和 33 个策略组。

- 标准配置 `LoonKit.lcf` 的分流、DNS、TUN、IPv4、IPv6 和现役插件内容均保持不变。
- AdBlock 仍支持 `REJECT` / `DIRECT` 选择；`GEOIP,CN,DIRECT,no-resolve` 与 `FINAL,Final` 保留。
- 采用 43 份独立锁定输入（33 份冻结规则、10 份本地规则），正式版可离线重建并逐字节验证。
- 删除不再使用的 `LoonKit.PrivacyDNS.lcf`、旧 `rules/generated/`、`rules/ProxyProtect.list`、v5 活动清单和重复独立插件别名。旧订阅到这些地址将失效。
- 历史来源和许可证证据保留，尚未完成的第三方许可判断不被标记为已批准。

## 网络诊断修复

- 将代理探测改为 HTTPS 204 目标，避免旧 HTTP 目标返回 301 时误报代理故障。
- HTTP 重定向和远端站点非预期状态码改为待确认；超时、TLS 错误等传输错误仍报告故障。
- Loon DNS 返回 `auto`、不完整元数据或缓存时明确标记协议未验证，不推断发生或未发生 DNS 泄漏。
- 新增版本化 JS 和 HTTP 301、自动提醒、DNS auto / 缓存回归测试。

## 诊断提示与使用说明完善（v6.0.0 维护更新）

- 直连、代理检测正常且 DNS 返回 `auto / https://` 等不完整元数据时，显示「网络连接正常，DNS 协议信息待确认」，不再误称“部分项目不可用”。
- 缓存解析不再被当作新的 DoH 网络传输证明，明确的普通 DNS 查询仍提示风险。
- 网络切换提醒统一中文标题及正文，保留默认关闭和提醒冷却。
- README 补充导入步骤、策略组功能、诊断插件和规则更新说明。

## 网络辅助诊断修正（2026-10-21）

- 网络连通性与 DNS 解析分开判断：DNS 解析成功但协议元数据不完整时，不再把警告放在主结论中。
- 完整 `auto + https://dns.alidns.com/dns-query` 可按 Loon 的服务器格式规则标注为 DoH；只返回 `https://` 时仍保留必要说明，不夸大已验证的传输证据。
- 普通 DNS 解析成功属于**成功但有隐私提示**，不再误报成解析失败；缓存命中同样不用于证明本次加密传输。
- `generate_204` 端点若返回 HTTP 200，不再视为正常（可能为认证门户），按待确认处理。
- 新脚本和插件采用新的固定提交路径，旧版固定资源不覆盖；正式规则及 DNS/TUN 设置没有调整。

## 正式资产目录整理（2026-10-21）

- 正式版使用统一的 34 个 PNG 图标快照；HBO 与其余 32 个策略组图标同目录，另含插件图标。
- 正式插件固定为单一 `release/Network_Diagnostics.plugin`，现役脚本集中在 `scripts/v20261021r1/`。
- 历史图标目录、旧插件与无现役引用的诊断脚本从 `main` 移除；**不改写历史提交**，既有固定 Raw URL 保持可用。
- 同步完善 README 对上游规则审核、去重和收紧能力的准确说明，未开启自动覆盖线上规则功能。

## 2026-10-21 · DNS 自由选择与规则候选审核

- 诊断插件不再要求用户 DNS 与 AliDNS 一致，按 Loon 原生 API 报告显示 DoH、DoT、普通 DNS 或元数据不足。
- 新增定期上游候选生成器：保存 87 条来源记录对应的可获取快照、规范化规则、去重结果、完整增删差异和跨策略冲突报告。
- 上游变化始终不会自动修改 `rules/inputs/`、规则锁或正式配置，防止意外扩大/缩小分流范围。

## 2026-10-21 · 上游规则误分流防护强化

- 自动审查拒绝明显的公共后缀、多租户托管根域、畸形域名、过短关键字与极宽 IP 匹配。
- 增加域名精确匹配和后缀匹配的区分，避免误报子域覆盖；增加 IPv4/IPv6 跨策略网段重叠检测及支付/登录/共享 CDN 误杀标记。
- 输出 `FULL_RISK_AUDIT.json`，提供逐规则风险、来源 ID 与删除审查记录。
- **上游候选 `*.list` 仅包含正式基线**，新增/删除提案不会混入可直接订阅的文本。CI 新增 26 组候选与正式规则相同的校验，不修改任何现役分流、DNS 或 TUN。

## 2026-10-21 · 规则风险分级校正

- 只对确实无法解析的匹配报格式错误；合法但覆盖范围较大的公共后缀、多租户服务、短关键词与大 IP 段保留来源并标记风险。
- 区分 `STANDARD` 常规审阅和 `ELEVATED` 优先审阅；普通新增后缀不再仅因规则类型被归类为高风险。
- 两类合法候选均只存在于完整差异和风险报告，不会自动发布；冻结的正式规则不变。

## 2026-10-21 · 独立多维度安全验证

- 上游 `DOMAIN-SET` 解析保留无前导点的精确 `DOMAIN` 与前导点的 `DOMAIN-SUFFIX`，避免因错误格式转换扩大匹配范围。
- v2fly 行尾来源注释可按格式解析，不误判正常域名为无效；不支持的正则和递归包含依然需要审核。
- 增加可重复的随机差分测试：域名交叉、IPv4/IPv6 网段、同策略去重前后匹配行为、异常输入及现役关键业务保护。
- 仅更改候选检查脚本、测试、CI 与说明；已固定的正式规则及 DNS/TUN 参数不变。
