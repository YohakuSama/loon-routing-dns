# LoonKit v6.0.0 · 正式发布变更说明

本版从 v5.10.0 大版本升级规则引擎与分流结构；选择主版本号 v6.0.0 是因为远程规则订阅数量、分组入口与规则归属发生兼容性变化。主配置仍使用 `LoonKit.lcf` 和 `LoonKit.PrivacyDNS.lcf` 的原有订阅路径。

## 新增与变更

- 自托管 26 条远程规则订阅，共 197,765 条规则；106 条本地规则、33 个策略组。
- 统一两份正式配置的分流内容，同时**分别按字节保留**各自 General、DNS/DoH、TUN、IPv6 和原有解析回退配置。
- 移除独立 ProxyProtect；旧 17 项名单保留归档，不用于检测网站特殊代理白名单。
- 保留 AdBlock 本地优先级保护（26 项）、国内支付/银行等重点归属、七条 ASN `no-resolve`、独立海外服务基本策略入口。
- 历史来源与生产输出隔离：33 份冻结合并规则放在 `rules/snapshots/phase03/generated/`，旧 `rules/generated/` 仅保留兼容；RC2 规则放在版本化目录并固定 Git SHA。
- 引入离线规则构建、来源锁、SHA256 校验、回归测试、许可证原文/NOTICE、只读 CI、main 合并预演及回滚说明。
- 资源固定脚本与图标版本，CI 不自动推送、覆盖规则或合并。
- 两份完整配置中取消“NOT RELEASED”候选标记，统一使用正式配置头 `LoonKit v6.0.0`；配置具体 SHA256 以 `RC_MANIFEST.json` 为准。

## 注意事项

- **旧的 34 条远程订阅不能直接当作新版 26 条的等价映射**；请从完整配置升级，移除失效的单独订阅并恢复自己的私人节点。
- AdBlock 的 REJECT/DIRECT、Final 四种选择会影响实际出口；Final=DIRECT 对未知海外域名有直连风险。
- 不对 DNS、IPv6、全部业务和地区解锁作绝对保证。维护者已报告真机使用无明显问题，但未提供全部专项结构化证据。
- 保留 GPL-2.0、MIT、WTFPL 的完整许可证副本及历史来源清单；具体混合来源的授权判断应以真实证据为准，历史逐行归属不可完整恢复。
- 回滚时不仅恢复 Git 代码，还须在 Loon 客户端恢复旧配置和私人节点，清理/刷新远程规则与插件缓存。
