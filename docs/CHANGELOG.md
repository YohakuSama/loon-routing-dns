# LoonKit 更新记录

## v6.3.0

- 「网络辅助」三个入口统一为「节点信息」「网络检测」「服务检测」，插件说明与设置文案重新整理。
- 服务选择默认显示「请选择服务」，不同服务附带用途标签；未选择时不发起检测请求。
- 服务检测结果改为网站、相关资源和 DNS 解析状态，仅在异常时给出简短建议，不再显示无必要的 HTTP 与 A/AAAA 技术细节。
- 清理主分支中不再使用的早期诊断脚本和独立插件资源，历史固定版本仍可通过原 Release 使用。

## v6.2.0

- 服务连通性诊断合并到现有「网络辅助」，正式配置只引用一个插件；节点出口、网络与 DNS 检查、网络切换提醒继续提供。
- 精简诊断弹窗，HTTP 404 等普通端点响应不再暗示 App 故障；增加服务主站的原生 DNS A/AAAA 检查。
- 保留 v6.1.0 的七项服务分流规则、广告拦截和原有 DNS、IPv6、TUN 配置，不强行添加可能干扰现有服务的共享 CDN 或宽 IP 规则。

## v6.1.0

**诊断与维护修正（不改变 v6.1.0 已发布配置）：** 日志和脱敏排查工具现可正确归类 v6.1.0 新增的 62 条精选域名；历史 v6.1.0 Release 发布工作流可重复执行完整性检查，不会因之后的文档或工具提交误判既有版本标签为异常。

- Spotify、Twitch、Abema、BBC、Line、Reddit 和 LinkedIn 新增 62 条经过筛选的域名后缀分流，常见静态资源与服务入口能更准确地进入对应策略。
- 正式配置新增「服务连通性诊断」，按需手动检测每项服务的两个代表性 HTTPS 端点，不会自动运行。
- 保留候选规则审计、离线命中模拟与脱敏日志异常分类，可按排查指南定位问题。
- 升级时需备份个人节点并刷新远程资源；此版本不改变已有 DNS 设置和 26 份固定远程规则。

## v6.0.0

## 分流与策略

- 提供 26 份固定版本远程规则与 33 个策略组，覆盖国内常用服务、AI、流媒体、社交和游戏。
- 支持手动选路、自动延迟测试和故障回退；`AdBlock` 策略组可切换广告拦截与放行。
- 支持根据需要选择 DNS 解析器。

## 网络辅助

- 提供节点出口 IP、地区、运营商和 ASN 信息。
- 支持直连、代理连接及 DNS 解析诊断，分别显示连通性与解析结果。
- 对 HTTP 非预期状态及 DNS 协议信息不足提供具体提示。
- 支持可选的网络切换提醒，默认关闭。

## 安装与更新

- 正式配置：[`LoonKit.lcf`](../LoonKit.lcf)。
- 导入后添加自己的代理节点或订阅，选择所需策略组，再刷新远程规则和插件资源。
- 从已有配置升级前建议先备份个人节点与自定义设置。
