# LoonKit 更新记录

## v6.4.4

- 解锁检测改为参考脚本实际执行的七项：DAZN、Discovery+、Paramount+、Disney+、Netflix、ChatGPT、YouTube Premium。
- 移除 Gemini、Spotify、TikTok、Claude 及「完整检测」开关。
- 直接显示「已解锁、未解锁、检测失败」，Netflix 另外显示「仅自制剧」，不再使用「待确认」。
- Netflix 和 YouTube Premium 采用参考脚本的 HTTP 判定方式；继续保留错误处理与所选节点检测。


## v6.4.3

- 解锁检测精简请求和备用流程，缩短常用节点的检测路径。
- 统一显示「支持、不支持、待确认、检测失败」，Netflix 部分内容可访问时单独显示「部分支持」。
- 改进 Netflix、Disney+、YouTube Premium 和 AI 服务的判断，接口异常不再直接当成节点不支持。

## v6.4.2

- 解锁检测结果简化为「可用、不可用、部分可用、可连接、检测失败」，每个平台只显示一行。
- Disney+ 优先请求较快的 BAMTech 地区接口，无结果时才进行备用检测。
- 不再在结果中重复显示 CDN、接口和网页等技术细节；DNS、分流及节点信息保持不变。


## v6.4.1

- Netflix CDN 检测到的国家单独显示为 CDN 地区，不再和视频片库状态混为一谈。
- Disney+ 保留网站地区回退，具体写明是页面地区而不是已解锁。
- Gemini 提前检测，主页异常时尝试 AI 接口连通；ChatGPT iOS 已知接口响应不再直接显示请求失败。
- 修正 Netflix 普通登录页面及不匹配的重定向可能误报片库可看的问题。


## v6.4.0

- Netflix 在两部测试影片均无法访问时增加第三部影片交叉判断，避免仅凭 404 猜测片库权限。
- Disney+ 地区接口失效时使用主页地区或连通信息兜底，区分服务支持与网页可访问。
- YouTube Premium 可单独识别订阅页面；Gemini 优先请求较轻量页面并限制追加检测。


## v6.3.9

- 修正 Disney+ 会话字段误匹配：只有有效的同一地区会话才能判定地区支持或受限。
- ChatGPT 的安全验证拦截不再直接作为地区限制；Gemini 页面地区码不再对应静态封锁名单。
- 统一检测提示和帮助说明，并修复历史版本更新日志标题重复的问题。


## v6.3.8
- Disney+ 改为匿名设备注册、令牌交换和地区会话查询，不再仅检查网站首页。
- Netflix 增加标题页面响应头校验；明确地区限制与接口拒绝相区分。
- 为多步检测调整等待上限，保持现有 DNS 和分流不变。


## v6.3.7
- 节点信息分别显示 Loon 配置的入口服务器与实际出口 IP，不把两者当作同一地址。
- 可选直连出口对照改为并行查询，减少等待。


## v6.3.6
- 优化 YouTube Premium 页面、Gemini 地区字段、TikTok 与 Claude 双请求检测，补足此前大量没有明确结果的项目。
- 将正常网站访问、地区接口支持、服务受限、请求失败分别列出，不以普通网页连接冒充真实播放权限。
- 保留同一被测节点出口和有限并发，补充更多平台异常回归测试。


## v6.3.5
- 服务检测结果改成清楚的状态说明，不再展示「可能可用」「开放信号」。
- 缩短默认检测等待时间，优化 Netflix 和 YouTube Premium 的独立判断，并保留接口与地区证据的区分。
- 修正维护日志中重复的版本标题。

## v6.3.4

- 流媒体与 AI 检测进一步区分服务可用信号、CDN 出口地区与网站是否能打开，减少错误解锁提示。
- 补充 Netflix CDN 辅助判断、Spotify 地区跳转及 HTTP 响应异常处理。
- 检测结果末尾显示脚本版本，方便排查 Loon 是否仍在使用旧插件缓存。


## v6.3.3

- 改进流媒体与 AI 地区判定：仅凭网站连通或出口地区不再显示解锁成功。
- 区分请求超时、连接异常、地区受限和未确认；短暂网络错误最多重试一次。
- 限制同一节点并发请求数量，优化多项请求失败时的结果说明。


## v6.3.2

- 将服务检测调整为「解锁检测」，采用针对流媒体和 AI 的地区接口与内容判定，不再用首页连接成功冒充解锁。
- 默认进行快速检测，完整检测可在插件设置中开启；限制并发和最长等待时间。
- 改用独立的播放图标，检测结果逐行显示服务状态；没有足够证据时显示未确认。

## v6.3.1

- 服务检测改为一次检查所选节点的常用服务，不需要再选择 Spotify 或其他单项服务。
- 所有检测通过同一个被检测节点发起，并区分网页可访问、地区限制、连接失败与无法判断的结果。
- 清理插件设置及说明中的冗余选择项，保留原有节点信息、网络检测与网络切换提醒。


## v6.3.0

- 「网络辅助」三个入口统一为「节点信息」「网络检测」「服务检测」，插件说明与设置文案重新整理。
- 服务选择默认显示「请选择服务」，不同服务附带用途标签；未选择时不发起检测请求。
- 服务检测结果改为网站、相关资源和 DNS 解析状态，仅在异常时给出简短建议，不再显示无必要的 HTTP 与 A/AAAA 技术细节。
- 清理主分支中不再使用的早期诊断脚本和独立插件资源，历史固定版本仍可通过原 Release 使用。

## v6.2.0

- 服务连通性诊断合并到现有「网络辅助」，正式配置只引用一个插件；节点出口、网络与 DNS 检查、网络切换提醒继续提供。
- 精简诊断弹窗，HTTP 404 等普通端点响应不再暗示 App 故障；增加服务主站的原生 DNS A/AAAA 检查。
- 保留 v6.1.0 的七项服务分流规则、广告拦截和原有 DNS、IPv6、TUN 配置，不强行添加可能干扰现有服务的共享 CDN 或宽 IP 规则。

## v6.1.0

**诊断与维护修正（不改变 v6.1.0 已发布配置）：** 日志和脱敏排查工具现可正确归类 v6.1.0 新增的 62 条精选域名；历史 v6.1.0 Release 发布工作流可重复执行完整性检查，不会因之后的文档或工具提交误判既有版本标签为异常。

- Spotify、Twitch、Abema、BBC、Line、Reddit 和 LinkedIn 新增 62 条经过筛选的域名后缀分流，常见静态资源与服务入口能更准确地进入对应策略。
- 正式配置新增「服务连通性诊断」，按需手动检测每项服务的两个代表性 HTTPS 端点，不会自动运行。
- 保留候选规则审计、离线命中模拟与脱敏日志异常分类，可按排查指南定位问题。
- 升级时需备份个人节点并刷新远程资源；此版本不改变已有 DNS 设置和 26 份固定远程规则。

## v6.0.0

## 分流与策略

- 提供 26 份固定版本远程规则与 33 个策略组，覆盖国内常用服务、AI、流媒体、社交和游戏。
- 支持手动选路、自动延迟测试和故障回退；`AdBlock` 策略组可切换广告拦截与放行。
- 支持根据需要选择 DNS 解析器。

## 网络辅助

- 提供节点出口 IP、地区、运营商和 ASN 信息。
- 支持直连、代理连接及 DNS 解析诊断，分别显示连通性与解析结果。
- 对 HTTP 非预期状态及 DNS 协议信息不足提供具体提示。
- 支持可选的网络切换提醒，默认关闭。

## 安装与更新

- 正式配置：[`LoonKit.lcf`](../LoonKit.lcf)。
- 导入后添加自己的代理节点或订阅，选择所需策略组，再刷新远程规则和插件资源。
- 从已有配置升级前建议先备份个人节点与自定义设置。
