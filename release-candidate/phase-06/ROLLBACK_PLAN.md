# Rollback

Before testing, export the currently functioning Loon configuration and record selected groups and rule versions privately. If RC fails, disable the candidate configuration, restore the exported official profile and original node subscriptions/selections, refresh or re-download official rule resources explicitly, and inspect active rule URLs and actual rule-hit logs. Do not assume cache invalidation or automatic resource refresh. Keep sensitive export only on the device. Production files and subscriptions in GitHub are not modified by RC work.
